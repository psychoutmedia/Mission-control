## LeetCode Practice

### Problem 1: Find the Duplicate Number (287) - Medium
- **Algorithm**: Floyd's Tortoise and Hare (cycle detection)
- **Time**: O(n), **Space**: O(1)
- **Key insight**: Treat array as linked list where nums[i] points to next node. Duplicate creates cycle.
- **Code**: Two-phase detection - find intersection, then find cycle entrance

### Problem 2: Merge Intervals (56) - Medium
- **Algorithm**: Sort + single pass merge
- **Time**: O(n log n), **Space**: O(1) extra
- **Key insight**: Sort by start time, then merge overlapping intervals
- **Code**: Keep track of last merged interval, expand if overlap

### Problem 3: Longest Substring Without Repeating (3) - Medium
- **Algorithm**: Sliding window with hash map
- **Time**: O(n), **Space**: O(min(m)) where m = charset size
- **Key insight**: Track last seen index of each char, move left pointer when duplicate found

### Problem 4: Find All Anagrams (438) - Medium
- **Algorithm**: Fixed-size sliding window with character count array
- **Time**: O(n), **Space**: O(1) - fixed 26 chars
- **Key insight**: Compare frequency arrays, slide window one char at a time

### Problem 5: Decode String (394) - Medium
- **Algorithm**: Stack-based parsing
- **Time**: O(n), **Space**: O(n) for stack
- **Key insight**: Push (string, repeat count) on '[', pop and repeat on ']'

### Problem 6: Daily Temperatures (739) - Medium
- **Algorithm**: Monotonic decreasing stack
- **Time**: O(n), **Space**: O(n)
- **Key insight**: Stack stores indices of temps. When warmer temp found, calculate days until warmer for each popped element.
