# Claude Code & VS Code AI Agent Research

## Claude Code (Anthropic)

**What is it?**
- "Agentic" AI that can do work on your computer
- **Computer use**: Autonomous file management, coding, debugging
- **Multi-agent orchestration**: Lead agent coordinates sub-agents
- Full control over tool access and permissions

**Key Features:**
- Autonomous code generation & debugging
- File management & computing tasks
- Research assistance (paper writing)
- Tool access control
- Orchestration of specialized sub-agents

**Use cases:**
- Software development (autonomous debugging, feature implementation)
- Research automation
- Document processing

## VS Code AI (GitHub Copilot)

- Inline code completion
- Chat interface for code questions
- Agent mode for autonomous debugging
- Multi-file editing

## Comparison for LLM Engineering

| Feature | Claude Code | VS Code AI |
|---------|-------------|------------|
| Autonomy | High | Medium |
| Multi-agent | Yes | Limited |
| Tool use | Extensive | IDE-focused |
| Orchestration | Built-in | Via extensions |

## Relevance

Claude Code demonstrates the agentic pattern Mark should understand:
1. Tool use (file, shell, browser)
2. Multi-agent orchestration
