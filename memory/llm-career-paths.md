# LLM Career Paths

## Roles

### 1. LLM Engineer
- Build AI agents
- Fine-tune models
- RAG systems
- $150-300K

### 2. ML Engineer
- Model training
- Infrastructure
- $140-280K

### 3. AI Researcher
- New architectures
- Publications
- $200-500K

### 4. Developer Relations
- Technical content
- Community
- $120-200K

## Skills Needed

### Technical
- Python (expert)
- PyTorch/TensorFlow
- Transformers
- Vector databases
- APIs

### Non-Technical
- Communication
- Problem-solving
- Business sense

1. Build portfolio (40+ agents ✅)

3. Blog/twitter presence
4. Apply to AI companies
