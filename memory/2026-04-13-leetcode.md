### 1. Binary Tree Level Order Traversal (Medium)
**Problem:** Given the root of a binary tree, return the level order traversal of its nodes' values (left to right, level by level).

**Approach:** BFS with queue — standard level-order traversal. Use a queue to process nodes level by level, tracking batch size for each level.

**Solution:**
```python
from collections import deque

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

def levelOrder(root):
    if not root:
        return []
    
    result = []
    queue = deque([root])
    
    while queue:
        level_size = len(queue)
        level = []
        
        for _ in range(level_size):
            node = queue.popleft()
            level.append(node.val)
            
            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)
        
        result.append(level)
    
    return result
```

**Complexity:** O(n) time, O(n) space (for queue + result)

**Key Insight:** BFS is natural for level-order. Alternative: DFS with depth parameter.

### 2. Validate Binary Search Tree (Medium)
**Problem:** Determine if a tree is a valid BST. In a valid BST, every node's left subtree contains only nodes with values less than the node's value, and every node's right subtree contains only nodes with values greater than the node's value.

**Approach:** DFS with valid range. For each node, pass the allowed min and max values from ancestors.

**Solution:**
```python
def isValidBST(root, min_val=float('-inf'), max_val=float('inf')):
    if not root:
        return True
    
    # Node's value must be within (min_val, max_val) exclusive
    if root.val <= min_val or root.val >= max_val:
        return False
    
    # Left subtree: max allowed = root.val
    # Right subtree: min allowed = root.val
    return (isValidBST(root.left, min_val, root.val) and
            isValidBST(root.right, root.val, max_val))
```

**Complexity:** O(n) time, O(h) space (recursion stack, h = height)

**Key Insight:** BST validation requires passing ancestor constraints down — not just checking local left/right values. Common mistake: only checking immediate children.

### 3. Coin Change (Medium — DP)
**Problem:** Given an array of coin denominations and a target amount, return the fewest number of coins needed to make up that amount. If impossible, return -1.

**Approach:** Bottom-up DP. `dp[i]` = minimum coins to make amount `i`. For each coin, transition: `dp[i] = min(dp[i], dp[i - coin] + 1)`.

**Solution:**
```python
def coinChange(coins, amount):
    # dp[i] = min coins to make amount i
    dp = [float('inf')] * (amount + 1)
    dp[0] = 0  # Base case: 0 coins for amount 0
    
    for coin in coins:
        for i in range(coin, amount + 1):
            dp[i] = min(dp[i], dp[i - coin] + 1)
    
    return dp[amount] if dp[amount] != float('inf') else -1
```

**Complexity:** O(n * amount) time, O(amount) space

**Key Insight:** Classic unbounded knapsack — coin can be used unlimited times. Fill dp table in coin-first order to allow repeated use. BFS alternative (shortest path) also works.

### 4. House Robber (Medium — DP)
**Problem:** Cannot rob two adjacent houses. Given an integer array `nums` representing the amount of money of each house, return the max amount you can rob.

**Approach:** DP with rolling window. For each house: rob it (add prevprev) or skip it (take prev). `dp[i] = max(dp[i-1], dp[i-2] + nums[i])`

**Solution:**
```python
def rob(nums):
    if not nums:
        return 0
    if len(nums) == 1:
        return nums[0]
    
    prevprev = nums[0]  # dp[i-2]
    prev = max(nums[0], nums[1])  # dp[i-1]
    
    for i in range(2, len(nums)):
        current = max(prev, prevprev + nums[i])
        prevprev = prev
        prev = current
    
    return prev
```

**Space Optimized:** Only need last two values — no full array needed.

**Complexity:** O(n) time, O(1) space

**Key Insight:** Two choices per step: rob or skip. State only depends on last two decisions. Space optimization to O(1) by keeping just two rolling variables.

## Patterns Identified

- **Tree BFS:** Queue-based level-order, track level size for batching
- **Tree DFS with range:** Pass ancestor constraints down for BST validation
- **DP: Bottom-up unbounded knapsack:** Fill dp in coin-first order for unlimited use
- **DP: Rolling window:** Space optimize from O(n) to O(1) when only last k states matter
