## 1. Number of Islands
**LeetCode #200** | Pattern: DFS / BFS on Grid

### Problem
Given an `m x n` 2D grid of `'1'` (land) and `'0'` (water), count the number of islands. An island is surrounded by water and formed by connecting adjacent lands horizontally or vertically.

### Solution

```python
from typing import List

def num_islands(grid: List[List[str]]) -> int:
    """
    DFS flood-fill: when we find a '1', DFS to mark the entire island,
    then increment count. Mark visited by turning '1' → '0'.
    """
    if not grid:
        return 0

    rows, cols = len(grid), len(grid[0])
    count = 0

    def dfs(r: int, c: int) -> None:
        # Base: out of bounds or water
        if r < 0 or r >= rows or c < 0 or c >= cols or grid[r][c] == '0':
            return
        # Mark as visited (sink the island)
        grid[r][c] = '0'
        # Explore 4 directions
        dfs(r + 1, c)
        dfs(r - 1, c)
        dfs(r, c + 1)
        dfs(r, c - 1)

    for r in range(rows):
        for c in range(cols):
            if grid[r][c] == '1':
                dfs(r, c)
                count += 1

    return count
```

### Key Insights
- **In-place modification** instead of a `visited` set — turn `'1'` → `'0'` as we go.
- Each cell visited exactly once → O(m×n) time.
- Classic flood-fill pattern that applies to many grid problems.

### Complexity
| | Time | Space |
|---|---|---|
| O(m × n) | O(m × n) worst-case (all land, recursion depth = m×n) |

## 2. Clone Graph
**LeetCode #133** | Pattern: Graph DFS / BFS with visited map

### Problem
Given a reference to a node in a connected undirected graph, return a deep copy (clone) of the graph. Each node contains a value and a list of its neighbors.

### Solution

```python
class Node:
    def __init__(self val=0, neighbors=None):
        self.val = val
        self.neighbors = neighbors if neighbors else []

def cloneGraph(node: 'Node') -> 'Node':
    """
    DFS with visited map: if node already cloned, return the clone.
    Otherwise, create clone, recurse for all neighbors, then return.
    """
    if not node:
        return None

    visited = {}  # old_node → new_node

    def dfs(n: 'Node') -> 'Node':
        if n in visited:
            return visited[n]

        # Clone current node
        clone = Node(n.val)
        visited[n] = clone

        # Clone all neighbors
        for neighbor in n.neighbors:
            clone.neighbors.append(dfs(neighbor))

        return clone

    return dfs(node)
```

### BFS Alternative

```python
from collections import deque

def cloneGraph_bfs(node: 'Node') -> 'Node':
    if not node:
        return None

    visited = {node: Node(node.val)}
    queue = deque([node])

    while queue:
        n = queue.popleft()
        for neighbor in n.neighbors:
            if neighbor not in visited:
                visited[neighbor] = Node(neighbor.val)
                queue.append(neighbor)
            visited[n].neighbors.append(visited[neighbor])

    return visited[node]
```

### Key Insights
- **Visited map is essential** to handle cycles and avoid infinite recursion.
- Map stores the mapping from original node → cloned node so we don't clone twice.
- Both DFS and BFS work — DFS is more elegant for this one.

### Complexity
| | Time | Space |
|---|---|---|
| O(V + E) — visit each node and edge once | O(V) — visited map + recursion stack / queue |

## 3. Sudoku Solver
**LeetCode #37** | Pattern: Backtracking with Constraint Propagation

### Problem
Write a program to solve a Sudoku puzzle by filling in the empty cells. A Sudoku solution must satisfy:
1. Each row contains digits 1-9 without repetition
2. Each column contains digits 1-9 without repetition
3. Each 3×3 subgrid contains digits 1-9 without repetition

### Solution

```python
def solveSudoku(board: List[List[str]]) -> None:
    """
    Backtracking with constraint propagation.
    Try empty cells one by one, checking all 3 constraints.
    Backtrack when stuck.
    """
    rows = [set() for _ in range(9)]
    cols = [set() for _ in range(9)]
    boxes = [set() for _ in range(9)]  # 3x3 subgrid sets
    empties = []

    # Initialize constraints from current board
    for r in range(9):
        for c in range(9):
            if board[r][c] == '.':
                empties.append((r, c))
            else:
                val = board[r][c]
                rows[r].add(val)
                cols[c].add(val)
                boxes[(r // 3) * 3 + c // 3].add(val)

    def box_index(r: int, c: int) -> int:
        return (r // 3) * 3 + c // 3

    def solve(pos: int) -> bool:
        # All empties filled → solved
        if pos == len(empties):
            return True

        r, c = empties[pos]
        b = box_index(r, c)

        for digit in '123456789':
            # Check all 3 constraints
            if digit not in rows[r] and digit not in cols[c] and digit not in boxes[b]:
                # Place digit
                board[r][c] = digit
                rows[r].add(digit)
                cols[c].add(digit)
                boxes[b].add(digit)

                # Recurse
                if solve(pos + 1):
                    return True

                # Backtrack
                board[r][c] = '.'
                rows[r].remove(digit)
                cols[c].remove(digit)
                boxes[b].remove(digit)

        return False  # no valid digit → backtrack

    solve(0)
```

### Key Insights
- **Constraint propagation**: instead of checking all 9 digits for every cell, the row/col/box sets propagate constraints — any digit already in a row/col/box is immediately excluded.
- **Backtracking**: try a digit → recurse → if dead end, undo and try next.
- **Indexing for boxes**: `(r // 3) * 3 + c // 3` maps (row, col) to one of 9 boxes.
- Sudoku is NP-complete — backtracking is the standard approach.

### Complexity
| Time | Space |
|---|---|
| O(9^81) worst-case (brute force), but constraint propagation cuts it drastically | O(81) for sets + recursion |

## Summary

| Problem | Pattern | Key Concept |
|---|---|---|
| Number of Islands | DFS flood-fill | In-place marking (`'1'` → `'0'`) |
| Clone Graph | Graph traversal + memo | Visited map handles cycles |
| Sudoku Solver | Backtracking + constraints | Row/col/box sets prune search space |

All three share the **graph traversal mindset**: visit each node/cell once, track state, backtrack when stuck.
