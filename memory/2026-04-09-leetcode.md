## 1. Binary Tree Inorder Traversal
**LeetCode #94** | Pattern: Tree DFS / Stack

### Problem
Given the root of a binary tree, return the *inorder* traversal of its nodes' values (left → root → right).

### Solution

```python
from typing import Optional, List

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

# Recursive
def inorder_recursive(root: Optional[TreeNode]) -> List[int]:
    result = []
    def dfs(node):
        if not node:
            return
        dfs(node.left)
        result.append(node.val)
        dfs(node.right)
    dfs(root)
    return result

# Iterative (stack-based)
def inorder_iterative(root: Optional[TreeNode]) -> List[int]:
    result = []
    stack = []
    curr = root
    while curr or stack:
        while curr:           # Go all the way left
            stack.append(curr)
            curr = curr.left
        curr = stack.pop()   # Process node
        result.append(curr.val)
        curr = curr.right     # Move to right subtree
    return result
```

**Recursive idea:** Classic DFS. Left subtree → root → right subtree. Python call stack handles the state.

**Iterative idea:**模拟递归. Keep going left and pushing nodes onto a stack. When you can't go left anymore, pop, process, then move right. Avoids recursion depth issues.

### Complexity
| | Time | Space |
|---|---|---|
| Recursive | O(n) | O(h) call stack — O(n) worst, O(log n) balanced |
| Iterative | O(n) | O(h) stack — O(n) worst, O(log n) balanced |

## 2. Merge Intervals
**LeetCode #56** | Pattern: Sorting / Greedy

### Problem
Given an array of intervals, merge all overlapping intervals.

### Solution

```python
from typing import List

def merge(intervals: List[List[int]]) -> List[List[int]]:
    if not intervals:
        return []
    # Sort by start time — key insight
    intervals.sort(key=lambda x: x[0])
    merged = [intervals[0]]
    for start, end in intervals[1:]:
        last_end = merged[-1][1]
        if start <= last_end:              # Overlapping or touching
            merged[-1][1] = max(last_end, end)  # Extend
        else:
            merged.append([start, end])   # No overlap, new interval
    return merged
```

**Idea:** Sorting by start time ensures we only ever need to compare with the *last* merged interval. If the current interval overlaps with it (start ≤ last_end), we extend. Otherwise, it's a fresh interval.

### Complexity
| Time | Space |
|---|---|
| O(n log n) sort | O(n) output + O(1) extra (in-place sort) |

## 3. LRU Cache
**LeetCode #146** | Pattern: HashMap + Doubly Linked List

### Problem
Design a cache that evicts the **Least Recently Used** item when full. Both `get` and `put` must be O(1).

### Solution

```python
class LRUCache:

    class _Node:
        __slots__ = ('key', 'val', 'prev', 'next')
        def __init__(self, key=0, val=0):
            self.key = key
            self.val = val
            self.prev = None
            self.next = None

    def __init__(self, capacity: int):
        self.capacity = capacity
        self.cache = {}          # key -> Node (O(1) lookup)
        # Sentinel head (LRU side) and tail (MRU side)
        self.head = self._Node()
        self.tail = self._Node()
        self.head.next = self.tail
        self.tail.prev = self.head

    def _remove(self, node):
        """Detach node from linked list."""
        node.prev.next = node.next
        node.next.prev = node.prev

    def _insert_at_tail(self, node):
        """Insert node just before tail = Most Recently Used."""
        node.prev = self.tail.prev
        node.next = self.tail
        self.tail.prev.next = node
        self.tail.prev = node

    def get(self, key: int) -> int:
        if key not in self.cache:
            return -1
        node = self.cache[key]
        self._remove(node)
        self._insert_at_tail(node)   # Mark as MRU
        return node.val

    def put(self, key: int, value: int) -> None:
        if key in self.cache:
            node = self.cache[key]
            node.val = value
            self._remove(node)
            self._insert_at_tail(node)
        else:
            if len(self.cache) >= self.capacity:
                lru = self.head.next       # Node after head = LRU
                self._remove(lru)
                del self.cache[lru.key]
            new_node = self._Node(key, value)
            self._insert_at_tail(new_node)
            self.cache[key] = new_node
```

**Idea:** Two data structures working together:
- **HashMap** (`cache`): key → node for O(1) lookup
- **Doubly Linked List**: maintains access order. Head = LRU, Tail = MRU. Sentinel nodes avoid null checks.

`get` → find node, move to MRU tail. `put` → if new, evict LRU (head.next) if at capacity, then insert at MRU tail.

### Complexity
| | Time | Space |
|---|---|---|
| get | O(1) | — |
| put | O(1) | O(capacity) |
