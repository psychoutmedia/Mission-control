## Security Incident - Phexia/PXA Stealer Malware

### Incident Summary
- **Malware Found**: `ixxjeiijvivzovon` - macOS stealer using Telegram C2
- **Infection Date**: Feb 16, 2026 at 13:11
- **Discovery Date**: Mar 4, 2026
- **Persistence**: LaunchAgent at `~/Library/LaunchAgents/com.bashsrc.ixxjeiijvivzovon.plist`

### What Happened
1. Phexia/PXA Stealer malware infected the Mac mini
2. Stolen data: Telegram session, browser data, possibly keychain
3. Attacker used Telegram session to join "dealz shopping" scam channel
4. Malware ran for ~2 weeks before discovery and removal

### Investigation Findings
- **Malware deleted**: `~/Library/ixxjeiijvivzovon`
- **LaunchAgent removed**: `~/Library/LaunchAgents/com.bashsrc.ixxjeiijvivzovon.plist`
- **No system daemons compromised**
- **GitHub clean** - no unauthorized access
- **SSH keys** - present but likely not compromised (would need Mac password)

### Indicators of Compromise (IOCs)
- File: `ixxjeiijvivzovon` in ~/Library/
- LaunchAgent: `com.bashsrc.ixxjeiijvivzovon.plist`
- C2 domains: kys.li, kys.cx
- Telegram bot: @phefuckxiabot

### Security Actions Taken
1. ✅ Malware file deleted
2. ✅ LaunchAgent removed
3. ✅ Chrome/Safari sessions killed
4. ✅ Daily security scan cron job set up (7am daily)
5. ✅ GitHub checked (clean)
6. ✅ SSH keys identified (should rotate)

### Recommendations
- Change all passwords (email, Amazon, banking, etc.)
- Enable 2FA on Telegram, Gmail, GitHub
- Change Mac user password
- Consider rotating SSH keys
- Enable 2-step verification on Telegram
