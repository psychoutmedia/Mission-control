# Meet Pascal: The Language That Taught Generations to Code

*Hello, World! — and hello to one of the most influential languages in computing history*

---

If you learned to code before Python took over, chances are you started with Pascal. Created in 1970 by Niklaus Wirth, Pascal was designed to teach programming rigorously—and ended up shaping how millions of developers think.

Pascal forces you to write clean, structured code. Variables must be declared. Types must be explicit. It's strict—but that's the point. The language teaches good habits.

**The legendary Hello World:**

```pascal
program HelloWorld;

begin
  WriteLn('Hello, World!');
end.
```

Simple, right? `program` names your file. `begin` and `end` wrap your code. `WriteLn` prints with a newline. No imports. No boilerplate. Just you and the logic.

**Why Pascal still matters today:**

- **Delphi** — the visual development environment that built Windows apps for decades
- **Turbo Pascal** — defined what a compiler IDE could feel like
- **Foundation** — C, Java, and Python all borrowed ideas from Pascal's structure

Whether you're curious about programming history or want a clean language to learn fundamentals, Pascal is worth a look. Install Free Pascal, type the code above, and run it.
